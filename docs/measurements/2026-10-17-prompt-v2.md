# Model eval: shipped prompt through the real OllamaClient (2026-10-17)

Spec: REQ-003, AC-003.4, AC-003.5, NFR-004, NFR-012, ADR 0004. Script: `scripts/eval_model.py`
(uses the package's `OllamaClient`, `prompt`, `presets` and `rules_engine`; prints aggregates
only, no context or model text). Presets are synthetic.

Rows: **v1** = prompt v1 on `6ea48d4` (dev before the filter fix); **v2** = prompt v2 on
`a8b2856` (stricter banned-word filter, `<`/`>` mapped in the note delimiter). Each row: 3 warm-up
calls (not counted), then 60 timed `assess()` calls cycling A, B, C (20 per preset). The model was
already loaded, so no cold time was measured (T-001: 2.0-3.4 s warm-after-idle, 11.5 s first load).
Latency is the `ModelResult.latency_ms` of the model step only (rules and alternative re-check are
pure Python and negligible). Percentiles: nearest-rank. "First-try valid" = the first attempt
passes `parse_model_output` (schema, limits, alternative, AC-003.5 content check).

## Caveats (be honest about the strength of this evidence)
1. Temperature 0 makes repeated calls on one fixed preset nearly deterministic, so the 20 runs per
   preset are close to one sample of the same prompt, not 20 independent trials. They show
   stability, not robustness to rewording of the note. AC-003.4 is met on the one real preset,
   which is what the AC asks, but a different note (e.g. a note naming acetylsalicylic acid in another language) could
   behave differently.
2. The AC-003.5 risk is latent: the home-medication ID (`aspirin`) is in the drug list and not the
   proposed drug or alternative, so any output that names it is rejected. It did not occur here
   because the model follows "refer to other medicines by class". If it occurs, the fail-safe outcome is
   the retry, then the rules-only card, which would lose preset A's BLOCKED escalation.
   Smallest fix if ever observed: spec option to exempt drug IDs present in the patient's
   `chronic_medications` from the other-drug check (they are the patient's own data, not new
   drugs, and dose patterns stay blocked). Expected impact: removes this failure class
   without weakening dose/alternative rules. Not needed now.
3. Brand names and synonyms (e.g. a Spanish brand name of aspirin) are not caught by the content check (known).
4. Not measured here: cold start, adversarial/injection notes, `pytest -m ollama` (not part of
   this brief), end-to-end `/api/check` p95 (check_service is T-005b).
