How it works

Gemma finds the facts. A rule table decides.

01

Gemma 4 reads

The note and the past history. It quotes each fact it finds, e.g. “Suspected ACS”

→
02

Code checks the quote

The words must really be there: not denied, not a relative's, not an old event counted as new

→
03

The rule table decides

Rules written by people from drug labels and guidelines, not learned by the AI. Same facts, same answer

→
04

One card

The verdict, the doctor's own words as evidence, a re-checked alternative

Example rule Anti-inflammatory (NSAID)+suspected ACS+aspirin →BLOCKED source: drug label (SmPC) + AHA statement · reviewed by a clinical specialist
Gemma can make a verdict stricter, never softer
Model down → the card says “free text not checked”

Why open weights · who would pay

The note never has to leave the building

Open weights make it practical

  • Gemma 4 can run on a hospital's own GPU
  • No patient context sent to a third-party model API
  • Inspect, pin and re-test the exact model
  • No per-call fee

Open core

  • Buyer: hospital pharmacy and medication-safety teams
  • The engine stays open source
  • Paid: a maintained, cited rule table
  • Paid: integration (FHIR, CDS Hooks) and support
