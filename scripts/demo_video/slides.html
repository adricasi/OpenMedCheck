Why open weights · who would pay

The note never has to leave the building

Open weights make it practical

  • Gemma 4 can run on a hospital's own GPU
  • No patient context sent to a third-party model API
  • Inspect, pin and re-test the exact model
  • No per-call fee

Open core

  • Buyer: hospital pharmacy and medication-safety teams
  • The engine stays open source
  • Paid: a maintained, cited rule table
  • Paid: integration (FHIR, CDS Hooks) and support
A hypothesis, not yet tested with buyers. Not CE-marked; not clinically validated.
